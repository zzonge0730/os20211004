---- ALGORITHMS ----

>> A2: Briefly describe what happens in a call to timer_sleep(),
>> including the effects of the timer interrupt handler.
When timer_sleep(ticks) is called, the current thread sets its wakeup_tick, inserts itself into the sleep_list (sorted by wakeup_tick), and blocks.
In timer_interrupt(), at each tick, the handler checks sleep_list and unblocks all threads whose wakeup_tick ≤ current tick.

>> A3: What steps are taken to minimize the amount of time spent in
>> the timer interrupt handler?
The sleep_list is kept sorted by wakeup_tick.
The interrupt handler only checks the front of the list and stops when it finds a thread not ready to wake up.

---- SYNCHRONIZATION ----

>> A4: How are race conditions avoided when multiple threads call

>> A5: How are race conditions avoided when a timer interrupt occurs
>> during a call to timer_sleep()?

---- RATIONALE ----

>> A6: Why did you choose this design?  In what ways is it superior to
>> another design you considered?
This design avoids busy waiting and uses a sorted sleep_list to efficiently manage sleeping threads.
It’s simple, minimizes CPU usage, and scales well.
Compared to scanning all threads each tick, it is more efficient and cleaner to implement.

// In thread.c
static bool
priority_more(const struct list_elem *a,
              const struct list_elem *b,
              void *aux UNUSED) {
  struct thread *t1 = list_entry(a, struct thread, elem);
  struct thread *t2 = list_entry(b, struct thread, elem);
  return t1->priority > t2->priority;
}
// Comparison function for inserting threads into ready_list in priority order.

// In thread.c (inside thread_unblock())
list_insert_ordered(&ready_list, &t->elem, priority_more, NULL);
// Ensures threads are added to ready_list in descending priority order.

// In thread.c (inside thread_yield())
list_insert_ordered(&ready_list, &cur->elem, priority_more, NULL);
// Keeps ready_list sorted by priority when current thread yields.

// In thread.c (inside thread_set_priority())
if (!list_empty(&ready_list)) {
  struct thread *highest = list_entry(list_front(&ready_list), struct thread, elem);
  if (highest->priority > thread_current()->priority)
    thread_yield();
}
// Causes current thread to yield if a higher-priority thread is waiting.
